SingleFile Auto Archiver — Setup

Every page you visit is saved automatically as a single HTML file. Each browser session gets its own subfolder (session_<date>_<time>/) containing session.txt (every URL with its status — QUEUE, INPROGRESS, DOWNLOADED — and timestamp) and a pages/ folder with the saved HTML files, named after the URL (gsmarena.com_phone_review.html).

1. Archive folder

Checking…

Chrome will ask you to allow the extension to “view and edit” this folder — choose Allow on every visit if offered, so access survives browser restarts.

2. Session log (session.txt)

One line per URL: URL STATUS time attempts. Pages you leave too early stay in QUEUE and are retried automatically. You can also hand-type a bare URL as a new line in session.txt — it gets downloaded within seconds. After 5 failed attempts a line is marked FAILED. Unfinished URLs carry over to the next session.
